# 🥑 Avocado Ripeness Classification Using Computer Vision

## 📌 Project Overview
This project explores computer vision and machine learning techniques for image classification. It compares traditional machine learning using HOG features and SVM with a deep learning approach using MobileNetV2.

## 🎯 Objectives
- Explore image preprocessing and feature extraction.
- Train and compare image classification models.
- Evaluate model performance using standard metrics.

## 🛠️ Technologies Used
- Python
- PyTorch and Torchvision
- OpenCV and PIL
- NumPy and Pandas
- Scikit-learn
- Matplotlib
- HOG and SVM
- MobileNetV2

## ⚙️ Methodology
1. Load and preprocess images.
2. Extract image features using HOG.
3. Train an SVM classification model.
4. Train a MobileNetV2 deep learning model.
5. Evaluate and compare model performance.

## 📊 Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Training time

## 🚀 Applications
- Fruit quality assessment
- Agricultural image analysis
- Automated fruit sorting

## 🔮 Future Improvements
- Use a verified avocado image dataset with clearly defined ripeness classes.
- Improve model accuracy with additional training data.
- Develop a simple web application for image-based predictions.
